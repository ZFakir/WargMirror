# IP-P1-2b — Replace the AI-Attribution Skeleton with a Truthful Declaration

**Register item:** MISSING_ITEMS.md §3, P1-2b (content for the Polish-F skeleton P1-2)
**Prerequisites:** IP-00. No code dependencies — this is a documentation/content task.
**Effort:** 1–2 hours of writing, dependent on team-member response time.

## 1. What is missing and why it matters for scoring

The brief requires AI usage attribution. Polish-F created `warg-docs/docs/10-ai-usage/ai-attribution.md` as a skeleton with placeholder rows/text. A template demonstrates awareness, but blank placeholders do not disclose the team's actual usage — a marker reading it will treat it as an unfulfilled requirement. This plan fills it with truthful, per-person, per-area declarations.

## 2. Current state (verified)

- `warg-docs/docs/10-ai-usage/ai-attribution.md` exists (skeleton with placeholders).
- `warg-docs/sidebars.js` — must be checked: if the docs sidebar is explicit (not autogenerated), the 10-ai-usage section needs an entry.

## 3. Implementation subtasks

1. **Collect declarations from every team member first** (chat/message each person; do not infer usage for anyone). Ask each for: tools used; work area or file/module; purpose (explanation, boilerplate, debugging, test ideas, refactoring); who reviewed the output; how it was verified (tests, manual run, peer review).
2. **Rewrite the page.** Replace every placeholder row/text with the collected data. Required columns per row: tool name · work area/file/module · allowed purpose · human reviewer · verification performed.
3. **Add the review policy paragraph:** what the team checks manually (logic, security, integration points) and automatically (lint, unit/integration tests, Playwright). Only claim peer review where it actually occurred.
4. **Non-AI-authored areas:** state them only where the team can support the claim (e.g. "game rules logic — hand-written, AI used only for test ideas" if true).
5. **Placeholder sweep:** after editing, run from repo root:
   `Select-String -Path warg-docs/docs/10-ai-usage/ai-attribution.md -Pattern 'placeholder','e.g.','Add one row','TODO','TBD','<','>'`
   …and confirm only legitimate content remains.
6. **Sidebar:** verify `warg-docs/sidebars.js` exposes the section; add it if the sidebar is explicit. Run `cd warg-docs; npm run build` and confirm the page renders in the sidebar navigation.
7. **README link:** defer the deployed-URL link to IP-P1-3; until then a relative mention ("see warg-docs/docs/10-ai-usage") is acceptable.
