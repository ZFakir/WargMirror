# WARG Platform

**Turn your campus into the game.**

WARG is a location-based Alternate Reality Game (ARG) and interactive scavenger hunt system for the Wits University campus. It lets members of the university create and participate in custom, location-based ARGs and scavenger hunts, with and against each other — empowering creators to plot geospatial data and define their own game logic.

This site is the technical and process documentation for the project, developed as part of the Software Design Project (COMS3011A) at the University of the Witwatersrand.
