# VJB Design System

The WARG platform's visual language is built on the **VJB System**.

## Design Philosophy

The visual language should support exploration rather than compete with it. Every design decision should help players navigate, understand, and enjoy the experience without unnecessary complexity.

| Principle | Meaning |
|---|---|
| **Exploration First** | Encourage curiosity and discovery through clear navigation and meaningful interactions. |
| **Clarity Over Decoration** | Prioritise usability and readability before visual complexity. |
| **Consistency Builds Trust** | Prefer reusable patterns over unique solutions. |
| **Gameplay Comes First** | The interface should support the game — not distract from it. |
| **Design for Growth** | The system should remain scalable as new features and game mechanics are introduced. |

## Colour Palette

| Swatch | Name | Hex | Role |
|---|---|---|---|
| 🟦 | P4 Phosphor Tint | `#99ACFF` | Primary Accent |
| 🟩 | P1 Phosphor | `#33FF33` | Secondary Accent |
| 🟫 | Computational Beige | `#C0B89B` | Brand Primary |
| ⬛ | Console Black | `#12100E` | UI Background |

Each colour is used across a tint/shade scale (50 → 900) for depth and state variation (hover, active, disabled) rather than introducing new hues.

## Typography & Spacing

- **Typeface:** Inter (optimised specifically for mobile)
- **Layout grid:** 4 columns, 24px margin, 16px gutter
- **Spacing system:** 8-point scale — 4, 8, 16, 24, 32, 48, 64px
- **Border radius:** 12px for buttons/inputs, 16px for cards/images

## Colour System Guidelines

1. Limit palette to 3 main colours.
2. Use accent colours sparingly.
3. Ensure text contrast meets WCAG.
4. Maintain colour consistency.
5. Use colour to guide action.
6. Test colour-blindness modes.
7. Group content by colour coding.
8. Use neutral backgrounds.
9. Document system updates.
