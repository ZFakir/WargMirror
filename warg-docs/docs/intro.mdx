# WARG Platform Documentation

Welcome to the official developer documentation for the **Wits Alternate Reality Game (WARG) Platform**.

This documentation site is generated from the project's various markdown files and design documents to provide a central source of truth for the architecture, methodology, and deployment of the platform.

## Structure

The documentation is organized into the following categories:

1. **Overview**: Project management methodology, task assignment, and meeting logs.
2. **Architecture and Design**: Technical implementation details for minigames, support systems, and the platform's visual design language.
3. **Database**: A comprehensive overview of the MySQL schema, spanning users, social networks, game states, and geospatial data.
4. **Deployment**: Step-by-step guides for hosting the backend on Render, the frontend on Vercel, and the database on Aiven.
5. **Policies**: Team collaboration rules, Git flow, and commit message conventions.

Feel free to browse through the sidebar to find the documentation you need!
