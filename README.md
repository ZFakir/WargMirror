# WARG Platform - Documentation

## About the Project

WARG Platform is a location-based Alternate Reality Game (ARG) and interactive scavenger hunt system. It allows organizers to create and run games where players move through real-world locations to complete challenges, earn points, and compete against each other.

The platform is built with a microservices architecture, separating the client-facing application from the backend business logic and database.

## Architecture Overview

The system consists of two main components:

1.  **WARG Client**: The frontend application where players interact with the game. It provides the user interface for viewing challenges, submitting answers, and tracking progress.
2.  **WARG Backend Services**: A collection of backend services that handle game logic, user management, scoring, and data persistence.
