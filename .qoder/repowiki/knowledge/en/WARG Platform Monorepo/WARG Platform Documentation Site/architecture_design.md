Static-site project built with Docusaurus 3.10 (preset-classic + theme-mermaid) on Node ≥20. Content is organized as MDX/Markdown under `docs/` (numbered sections: overview, architecture-and-design, database, deployment, policies, api-reference, frontend, testing, third-party, user-feedback) plus a `blog/` section; navigation is auto-generated from filesystem via `sidebars.js` (`tutorialSidebar`). Custom React components live in `src/components`, custom CSS in `src/css/custom.css`, and static assets in `static/`. The generated `.docusaurus/` folder holds the build-time registry/routes/globalData produced by Docusaurus. Deployment target is Cloudflare Pages via `wrangler.jsonc`.
