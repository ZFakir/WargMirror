The `server/src/app.js` factory builds a single Express app (no HTTP listener) that mounts every child module's routes under `/api/*` or `/auth`, while `server/server.js` wraps it in an `http.Server` plus a Socket.io instance for live game modes. Cross-cutting wiring is centralized: `src/config/database.js` exposes the Sequelize instance used by all models (`src/models/index.js`), `src/config/passport.js` provides local-login strategy, and `src/middleware/authMiddleware.js` supplies `requireAuth` / `requireAdmin` guards applied at mount time to `/api/game` and `/api/admin`. Session persistence uses MySQL-backed `express-mysql-session` in production and in-memory store in tests; both paths are selected via `NODE_ENV`. The `database/schema.sql` file defines the MySQL schema that Sequelize models map onto, and the seed/migration scripts (`seed.js`, `make_admin.js`, `dump_wp*.js`, `fix_wp.js`) operate against this same DB connection.
