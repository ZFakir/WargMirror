Single-controller leaf module split into three files: `minigameController.js` exposes three Express handlers (`uploadReference`, `getReferenceImage`, `submitAttempt`) mounted under `/api/minigames`; it owns the HTTP boundary (file upload handling, JSON responses) and delegates persistence to two Sequelize models. `Minigame.js` defines the game definition table (`minigames`) with a composite of `game_type` enum values and a `config_json` column used to store the embedded base64 reference image plus its MIME type. `MinigameAttempt.js` defines the per-user-per-game attempt log (`minigame_attempts`) with outcome/score/points fields. The controller is the only file that depends on both models; model files depend only on `../config/database`. External dependency direction: controller → AI service at `$AI_SERVICE_URL` (default `http://127.0.0.1:8000`) whose endpoint is selected by `game_type` (`shape_match`→`/api/v1/sam-extract`, `colour_match`→`/api/v1/hsv-match`, `texture_match`→`/api/v1/texture-match`, `sift_match`→`/api/v1/sift-match`, `symmetry_finder`→`/api/v1/symmetry`). Attempt records are not persisted here — the controller forwards the AI response directly to the client.
