Single-layer module: `argController.js` exposes Express handlers that directly call Sequelize models (`Arg`, `ArgVote`) and related domain models (`User`, `Waypoint`, `WaypointEdge`, `Minigame`, `Flag`) re-exported from `../models`. The two model files (`Arg.js`, `ArgVote.js`) define the `args` and `arg_votes` tables via `sequelize.define` with explicit column types and table names. Read endpoints (`getAllArgs`, `getArgById`) eagerly include `User` as `Creator` and a filtered `ArgVote` scoped to the requesting `user_id`, then flatten the vote into a top-level `user_vote` field. Write endpoints (`createArg`, `updateArg`) wrap multi-step inserts/updates of Arg → Waypoint → Minigame → WaypointEdge in a single `sequelize.transaction()` with explicit commit/rollback on success/error. Vote aggregation is denormalized: `voteArg` recomputes `like_count`/`dislike_count` on the `Arg` row after every vote mutation. Dependency direction is one-way: controller → models; no internal sub-packages.
