Two distinct sub-scopes sit side-by-side:
- `sessionController.js` is an Express-style controller exposing three async handlers (`startGameSession`, `getActiveSessions`, `removeRecentSession`) that delegate all persistence to a `GameSession` model (imported from `../models`, not defined here) and an `Arg` model, using Sequelize's `create`/`findAll`/`destroy` with where clauses scoped by `user_id`.
- `Waypoint.js` and `WaypointEdge.js` are standalone Sequelize model definitions bound to the shared `sequelize` instance from `../config/database`. `Waypoint` stores geospatial data via MySQL `GEOMETRY('POINT', 4326)` with a default validation radius and sort order; `WaypointEdge` is a timestampless edge table linking `from_waypoint_id` → `to_waypoint_id` within an `arg_id`, carrying optional `conditions_json`.
The controller depends on the session model layer; the two waypoint models are independent of the controller and each other — no associations are declared in this scope.
