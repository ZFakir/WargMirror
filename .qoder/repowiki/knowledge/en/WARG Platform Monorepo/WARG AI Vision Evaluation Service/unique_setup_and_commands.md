Requires the MobileSAM checkpoint file `weights/mobile_sam.pt` to be present alongside the code (copied into the Docker image); without it the SAM predictor initializes to `None` and the `/health` endpoint reports `"sam": false`. Container runs on port 8080 by default but honors the Cloud Run `$PORT` env var. Tesseract OCR engine and English language data must be installed at build time (handled by the Dockerfile's `apt-get install tesseract-ocr tesseract-ocr-eng`).
