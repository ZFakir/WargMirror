Single-process FastAPI application (`main.py`) exposing `/api/v1/*` endpoints behind an `X-API-Key` header guard and CORS middleware tuned for the Express frontend. Each endpoint is a thin HTTP adapter that delegates to a sibling module under `vision/`, which encapsulates one algorithm per file: `sam_extractor` (Meta MobileSAM with a 5-point crosshair prompt and Jaccard index), `hsv_matcher` (2D H-S histogram + Bhattacharyya distance), `mobilenet_extractor` (MobileNet-V2 ImageNet features + cosine similarity), `then_vs_now` (SIFT archival matching), `symmetry` (reflection symmetry score), and `ocr_matcher` (Tesseract plaque comparison). Model weights live in `weights/mobile_sam.pt` and are loaded at import time; missing weights degrade gracefully with a warning and a `None` predictor. The service is containerized via `Dockerfile` on `python:3.11-slim` with CPU-only PyTorch, OpenCV headless, and Tesseract installed as system deps, launched by `uvicorn main:app` on `$PORT`.
