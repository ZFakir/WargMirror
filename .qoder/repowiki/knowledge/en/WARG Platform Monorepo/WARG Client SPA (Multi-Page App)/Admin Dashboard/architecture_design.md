Single-page client module composed of three files: `admin.html` is the entry shell that loads shared design tokens (`styles/tokens.css`, `styles/home.css`, `styles/analytics.css`) plus page-specific `styles/admin.css`, then wires in shared components (`scripts/components/GameCard.js`, `scripts/components/ConfirmModal.js`), navigation state (`scripts/home.js`), configuration (`scripts/config.js` exposing `API_BASE_URL`), mock data (`scripts/data/games.js`), and finally the page controller `scripts/admin.js`. The JS bootstraps on `DOMContentLoaded`, renders skeleton placeholders while awaiting `/api/admin/flags`, delegates all click handlers via event delegation on container elements, and drives mutations through `fetch(..., { credentials: 'include' })` against the backend's `/api/admin/*` endpoints. UI state (active flag, modal visibility) lives in module-scoped variables; cross-cutting concerns like toast notifications and confirmation dialogs are consumed from global singletons (`showToast`, `window.confirmModal`) provided by other scripts.
