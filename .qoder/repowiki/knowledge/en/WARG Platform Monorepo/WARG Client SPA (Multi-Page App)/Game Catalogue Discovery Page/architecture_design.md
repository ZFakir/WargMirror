Three-file leaf module: `catalogue.html` is the page shell (shared app-shell with left sidebar navigation, topbar search/actions, and a right friends panel) plus script/style imports; `scripts/catalogue.js` is the single-page controller that runs on `DOMContentLoaded`, shows skeleton placeholders, calls `api.getArgs()`, then filters/sorts the in-memory array and delegates each item to `GameCard.create()` for DOM construction; `styles/catalogue.css` provides page-scoped styles (filter chips, sort select, responsive CSS Grid gallery, pagination). Dependency direction is one-way: this page depends on shared globals `api` (`scripts/api.js`) and `GameCard` (`scripts/components/GameCard.js`) but exposes no APIs itself. The HTML also links shared design tokens via `styles/tokens.css` and `styles/home.css` rather than defining its own palette.
