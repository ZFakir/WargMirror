Three-file leaf module: `analytics.html` is the entry page, embedding shared layout assets (`styles/tokens.css`, `styles/home.css`) plus its own `analytics.css`, and loading `scripts/config.js` then `scripts/home.js` (which provides the shared sidebar/drawer) before `scripts/analytics.js`. The JS file owns all interactivity — it holds in-memory mock data (`mockFlags`, `resolvedFlags`, `currentFlagId`), renders flag rows via template literals into `#flags-list`, and drives a `flag-modal-overlay` dialog that moves flagged items from active to resolved state. There is no network layer; API calls are stubbed with `alert()` placeholders, and destructive actions (remove WARG) navigate away via `window.location.href = 'studio.html'`. Styling uses BEM-style class names scoped under `.analytics-*` / `.flag-item-*` / `.action-card-*` and relies on CSS custom properties from `tokens.css` for colors, spacing, and typography.
