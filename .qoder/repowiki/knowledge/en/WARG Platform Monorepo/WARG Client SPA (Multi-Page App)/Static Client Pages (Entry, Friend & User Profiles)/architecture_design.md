Three independent `.html` files with no shared JS framework — each page is self-contained and pulls in shared CSS (`styles/tokens.css`, `styles/home.css`, `styles/profile.css`) plus `scripts/config.js`. `index.html` is a thin HTTP-redirect shim that forwards to `login.html`. `friend-profile.html` is a fully static mock of another player's profile (banner, avatar, stats, badges, action buttons) and only loads `scripts/home.js` for the shared app-shell/sidebar/topbar chrome. `user-profile.html` mirrors the same shell but adds dynamic sections (profile name/avatar, stats grid, badges grid, library grid) populated at runtime via `scripts/user-profile.js`, which depends on `scripts/api.js` and the reusable `scripts/components/GameCard.js`. Both profile pages share the same DOM skeleton (`.app-shell`, `.sidebar`, `.topbar`, `.main-content`, `.profile-container`) so the sidebar/topbar behavior in `home.js` works across pages.
