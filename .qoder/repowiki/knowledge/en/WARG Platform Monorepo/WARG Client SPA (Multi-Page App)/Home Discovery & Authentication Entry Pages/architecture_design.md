Three independent static HTML pages served by the web server:
- `home.html` is the authenticated app shell: a left sidebar (Discover / My Library / Creator Studio / Account / Settings), a topbar with search, notifications, friends-panel toggle, and avatar; a scrollable main area composed of Netflix-style horizontal rows (`row-recent`, `row-new`, `row-creators`) populated at runtime by `GameCard.renderRow()` from `scripts/components/GameCard.js`; a right panel showing stats, pending friend requests, online/offline friends, and a friend-search results list; plus feedback and friend-profile modals. It loads shared assets in order: `config.js` → `api.js` → `GameCard.js` → `home.js`.
- `login.html` and `signup.html` are minimal single-purpose forms styled via the shared `styles/login.css` (with `styles/tokens.css` as the design-token base). Login posts to `home.html` and delegates Google OAuth to `window.API_BASE_URL + '/auth/google'`. Signup includes an optional avatar picker (DiceBear pixel-art defaults plus file upload) and per-field error spans.
- Dependency direction is one-way: these pages depend on `scripts/config.js`, `scripts/api.js`, and their page-specific scripts (`home.js`, `login.js`, `signup.js`); they do not import each other.
