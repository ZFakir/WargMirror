# Design Principles and Colour System

The visual language of the WARG Platform should support exploration rather than compete with it. Every design decision should help players navigate, understand, and enjoy the experience without unnecessary complexity.

## Core Design Philosophy

1. **Exploration First:** Encourage curiosity and discovery through clear navigation and meaningful interactions.
2. **Clarity Over Decoration:** Prioritise usability and readability before visual complexity.
3. **Consistency Builds Trust:** Reusable patterns should be preferred over unique solutions.
4. **Gameplay Comes First:** The interface should support the game — not distract from it.
5. **Design for Growth:** The system should remain scalable as new features and game mechanics are introduced.

## Colour Palette

We utilise a structured colour palette inspired by modern UI needs and digital phosphors.

### Primary Colours
- **Brand Primary (Computational Beige):** `#C0B89B`
- **UI Background (Console Black):** `#12100E`

### Accent Colours
- **Secondary Accent (P1 Phosphor):** `#33FF33`
- **Primary Accent (P4 Phosphor Tint):** `#99ACFF`

## Colour System Guidelines

1. **Limit palette to 3 main colors.** Avoid creating a noisy UI by sticking strictly to our defined palettes.
2. **Use accent colors sparingly.** Accents are meant to draw the eye to critical interactive elements or alerts.
3. **Ensure text contrast meets WCAG.** Text must be easily readable on all backgrounds, particularly the Console Black.
4. **Maintain color consistency.** Don't redefine the meaning of a colour (e.g. green should consistently mean success/progress or primary action).
5. **Use color to guide action.** Interactive elements should visually indicate their interactability through consistent colouring.
6. **Test color blindness modes.** Ensure that the game is accessible by verifying that relying solely on colour is not the only way to convey meaning.
7. **Group content by color coding.** Similar content types or game features can share subtle colour cues.
8. **Use neutral backgrounds.** Console Black ensures content pops and reduces eye strain.
9. **Document system updates.** Keep this guideline up to date as new styles are integrated.
